# INK GLASS V1.0 · 首页复刻实施说明

## 设计基准

参考用户提供的「水波纹助手 / INK GLASS V1.0」首页图进行真实 Android View 复刻。这里只实现可交互的 UI 结构，不使用固定背景整图，也不生成假的设备或运行状态。

### 视觉规则

- **颜色**：黑、白、灰；主要色值依循 16 级灰阶 (00,11,...,EE,FF)
- **背景**：`InkGlassWaveView` 绘制的三条静态灰阶波形；无透明模糊、渐变、投影与动画
- **布局**：大标题、运行状态与胶囊主按钮、双列设备/动效卡片、2×2 功能卡、五项胶囊底导航
- **文字**：优先大号清晰文字；浅灰只承载非关键的装饰和背景
- **自适应**：正文可滚动，底部导航固定；支持小屏 Android 墨水屏，主操作不小于 48dp
- **系统状态栏**：使用真实 Android 状态栏，不伪造时间、Wi-Fi 或电量

### 数据绑定

- **设备型号、Android 版本**：直接来自 `Build.MODEL` 与 `Build.VERSION.RELEASE`。
- **监听状态**：来自 `SetupActivity` 绑定的 `ITouchService` 及 `isListening`。
- **模式、速度和方向**：来自现有 `ripple_prefs`，反向由 `reverse_animation` 设置控制。
- **接口已下发**：只在诊断窗口中作为服务日志显示，不等于实机波纹已验收。

### 功能入口

| UI | 动作 | 目前实现 |
|---|---|---|
| 主要胶囊 | 启动/停止监听，或提示连接 | 原 `toggleListening()` 和 Shizuku 连接 |
| 翻页效果 / 效果 | 打开效果配置 | 现有 `RippleActivity` |
| 应用管理 / 应用 | 编辑目标阅读应用 | 现有选择多选对话框（取消可回滚） |
| 连接向导 | 原有六步初始化 | 隐藏的旧版完整交互视图，可用返回键回首页 |
| 设备诊断 / 诊断 | 查看连接、输入及上次接口信息 | 只读诊断对话框；可刷新 |
| 设置 | 系统设置页 | 现有 `SettingsActivity` |
| 顶部信息 | 产品说明 | 轻量对话框 |

### 代码说明

- `activity_ink_glass_home.xml`：独立可绑定的首页布局
- `InkGlassWaveView.kt`：不拦截点击的静态波纹背景
- `ink_glass_colors.xml` / `ink_glass_*.xml`：灰阶 Token 与纯色形状
- `SetupActivity.kt`：在现有服务管理、初始化页面上增加独立首页 ViewBinding；不改底层厂商代码

采用并行保留旧六步初始化的过渡方案，避免 UI 重构时破坏已经通过的 Shizuku 服务接口。

### 测试边界

Gradle 单测和 Debug 编译必须在 GitHub Actions 对应提交运行通过。新增 Android Espresso 导航冒烟用例**仅提交测试源码**，没有设备就不能声称已跑通。图中所有厂商私有波纹方向仍需要实机验证，不能由 UI 编译结果推导硬件支持。
