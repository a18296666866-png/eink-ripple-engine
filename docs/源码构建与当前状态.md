# 构建与验收说明

## 源码基线

项目基于 [eink-page-turn-assistant](https://github.com/a18296666866-png/eink-page-turn-assistant) 固定提交 `ad84a5e28c899fdbd4cda288cf9d94497fe575c0` 完整迁移。保留 Apache-2.0 授权声明和上游出处。

## 整改范围

- **Gradle 与 CI**：修复本地属性空值、缺失模块路径、Debug 签名、SDK 配置；配置 Android 单测与 Debug 构建。仅当对应 GitHub Actions 运行成功时才能声明构建通过。
- **独立映射**：掌阅、汉王、大我拥有各自 Mapper，由 `RippleMapping` 统一分发；既有接口码的 96 组组合设为回归测试。
- **事件处理**：按键/触控识别、跨输入源重复去重、快速翻页、旋转采样、服务异常退出、结构化调用日志。
- **用户交互**：设置持久化、通过 AIDL 与后台同步，监听状态反馈、应用选择取消回滚、小屏布局。
- **权限与安全**：限制配对码读取范围及时间、敏感日志脱敏、原生 API 结果检查。
- **测试材料**：单元测试、Espresso UI 冒烟测试源码和 144 项实机记录清单。

## 编译

要求 JDK 17、Android SDK Platform 34 / Build Tools 34、NDK、CMake 3.22.1 和 Gradle wrapper：

```bash
git clone https://github.com/a18296666866-png/eink-ripple-engine.git
cd eink-ripple-engine
./gradlew :manager:testDebugUnitTest :manager:assembleDebug --no-daemon
```

Debug 构建自动使用 Android 开发调试签名。发布签名应在本地配置，**不得上传签名私钥**。

## CI 测试与已知边界

GitHub Actions 工作流：`.github/workflows/android-debug.yml`。此工作流执行 Kotlin/Java 单元测试与 Debug APK 打包；它**不会**执行连接真实设备的 Espresso 或硬件波纹测试。Android Instrumentation 测试源码保存在 `manager/src/androidTest/`，需要实际模拟器或 Android 设备单独执行。

实机测试请使用 [校准矩阵](qa/calibration.csv)；覆盖 3 厂商 × 2 模式 × 4 旋转 × 3 来源 × 2 方向，共 144 例。默认均为 `UNVERIFIED`，不可直接标为通过。

**质量口径：** 接口返回成功 ≠ 波纹方向正确；静态映射匹配 ≠ 设备兼容；CI 打包成功 ≠ 三品牌实机验收。

## 发布前复核

1. 新提交 Gradle CI 全绿，取得 Debug APK；
2. 在目标设备上至少验证原生服务权限、触摸/按键双输入、旋转四方向；
3. 清理重复事件、后台权限和锁屏恢复等边界异常；
4. 真实填写校准 CSV，对固件差异建立兼容清单；
5. 补充发布签名、版本号和变更日志后再考虑 Release。

旧源码编译产物 `out/` 未迁入本仓库，不能作为新代码验收依据。
