## Android 编译

依赖 Android SDK、Android NDK、CMake、JDK 17、Gradle wrapper 和可访问的依赖仓库。

```bash
git clone https://github.com/a18296666866-png/eink-ripple-engine.git
cd eink-ripple-engine
./gradlew :manager:testDebugUnitTest :manager:assembleDebug --no-daemon
```

### 已知可能阻断编译的问题

1. 根 `settings.gradle`：处理 `local.properties` 的逻辑需修复：`props['api.useLocal']` 可能为空，直接 `.equals('true')` 有空指针风险。
2. `manager/build.gradle`：引用根 `signing.gradle`，当前迁移树没有该文件，需配置签名方案。
3. `settings.gradle`：依赖 `api/hidden-api-stub`；请确认此模块是否存在并与编译 Gradle 配置一致。
4. 旧 CI 工作流已不兼容 `main` 与新的所有者，新 CI 应独立建设。
5. JNI 同时存在 `src/main/cpp` 和 `src/main/jni` 构建声明，需检查真实生效的 CMake 文件，避免两套配置冲突。

不要使用旧项目的已编译 APK 充当新源码的验证结果。
